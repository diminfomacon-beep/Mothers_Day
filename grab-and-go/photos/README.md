# Grab & Go photos

Upload one photo per product in this folder.
Name the file EXACTLY like the product name on the Grab & Go page,
for example: `20oz Skinny Tumbler.jpg` or `A5 Padfolio.png`.
Accepted: .jpg, .png, .jpeg — the page tries them in that order.
Photos appear on the Grab & Go page automatically once uploaded.
This folder is separate from catalog/photos/ because some product
names (e.g. 20oz Skinny Tumbler) exist on both pages with different
photos — the ready-made design here, the customizable blank there.
